# Requirements Checklist

- [ ] FR-001: System generates a report encompassing 9-point checklist, 3 trading setups, news, and earnings.
- [ ] FR-002: System runs on a 6-hour interval via an automated scheduler.
- [ ] FR-003: System sends report to user's Gmail address as an attachment.
- [ ] FR-004: System persists historical reports in a database table.
- [ ] FR-005: System provides a UI Dashboard to view and download historical reports.
- [ ] NFR-001: 100% DRY. Individual ticker checks in UI must mirror the report generator output precisely.
